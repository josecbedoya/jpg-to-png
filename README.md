# 🖼️ JPG to PNG convertor

![Python](https://img.shields.io/badge/Python-3.11-blue?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)

This Python script converts all the JPG images from a folder "image_folder" to PNG format and saves them in "output_folder". This is useful for converting large amounts of images at the same time. It prints "done!" only if all the images were converted succesfully.

## ⚙️ Installation

1. Clone the repository
```bash
git clone https://github.com/josecbedoya/jpg-to-png.git
cd jpg-to-png
```

2. Install dependences:

```bash
pip install Pillow
```

## 🚀 Usage

Run this script from the console, specifying both the image source folder and the output folder.

```bash
python convert.py path/to/images path/to/output
```
